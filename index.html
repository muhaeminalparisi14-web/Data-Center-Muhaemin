Cara Menghubungkan Kamera ke Sini

Tergantung pada merek CCTV Anda, Anda dapat mengganti teks <span>No Video Feed...</span> pada HTML di atas dengan cara berikut:

  • IP Camera Lokal (MJPEG):
    Jika kamera Anda mendukung *stream* lokal di *browser*, gunakan tag gambar:
    <img src="http://IP_Kamera_Anda/video.cgi" />
  • Cloud Web Viewer / NVR:
    Gunakan fitur sematkan (*embed*) Iframe:
    <iframe src="URL_WEB_CCTV_ANDA" frameborder="0"></iframe>
